## H1 persistent acquisition pilot

`v5/sources.json` configures reviewed selectors, stream weights and resource limits. Each run uses a private SQLite job ledger on the verified corpus device. Start with `make .build/v5-miner && .build/v5-miner pilot --steps 1`. Use the printed directory with `.build/v5-miner status DIR`, `resume DIR [--steps N]`, or `cancel DIR`. A cancellation closes queued jobs at the next job boundary. A deterministic qualification failure requires a reviewed new run. An interrupted attempt can run again within the configured retry ceiling. The host grants one worker lease, with one CPU, a per-process address-space limit, a wall deadline, a disk reservation and a network-isolated worker for each step.
